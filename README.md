## 🚀 В разработке

### [FunnyNodes](https://github.com/Funny-Code-d/xray-panel) — панель управления Xray-серверами

Открытая веб-панель для централизованного управления Xray-сервером и клиентами. Построена на Laravel + Vue 3, работает с Xray-core через VLESS + Reality.

**Что делает:**
- Управляет Xray-серверами — генерирует `config.json` из БД, отдаёт через API
- Выдаёт ключи доступа — `vless://` ссылки и QR-коды
- Собирает статистику — трафик по дням через Xray Stats API
- Мульти-сервер — один экземпляр панели управляет несколькими узлами
- Админ-панель — модерация, роли, блокировки, лимиты

**Стек:** Laravel 12 · Vue 3 · Sanctum · Tailwind CSS · Xray-core
